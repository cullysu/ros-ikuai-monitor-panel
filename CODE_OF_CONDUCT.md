# Code of Conduct

This project is for practical, read-only RouterOS status visibility. The
community should stay useful, specific, and safe for people operating real
networks.

## Expected Behavior

- Be respectful and direct.
- Keep issue and pull request discussions focused on reproducible behavior,
  evidence, and safe next steps.
- Redact RouterOS passwords, public IPs, tokens, private hostnames, MAC
  addresses, and screenshots that reveal sensitive network details.
- Assume maintainers and reporters are working with different network sizes,
  skill levels, and deployment constraints.

## Unacceptable Behavior

- Harassment, insults, threats, or repeated hostile comments.
- Sharing someone else's credentials, private network data, or personal
  information.
- Pressuring maintainers to provide unsafe RouterOS, firewall, NAT, routing, or
  remote-access changes without a backup and rollback path.
- Posting exploit details or sensitive vulnerability information in public
  issues.

## Enforcement

Maintainers may edit, hide, or remove comments and issues that are unsafe,
off-topic, or hostile. Repeated violations can lead to being blocked from the
project.

For security-sensitive reports, follow [SECURITY.md](./SECURITY.md).
