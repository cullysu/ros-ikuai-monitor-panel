# Disclaimer

This project is an independent read-only RouterOS status panel. It is not
affiliated with, endorsed by, or supported by MikroTik.

The panel summarizes operational evidence. It can be wrong, incomplete, stale,
or affected by RouterOS permission limits, API failures, SSH failures, sampling
windows, browser state, or deployment configuration.

Use it as a read-only status view, not as the sole source of truth for
production network changes. Keep RouterOS backups, verify important findings
with RouterOS tools, and define backup, rollback, and verification before
making live configuration changes.
