# Method Sources

This project skill is an original, project-specific workflow. It adapts process ideas rather than vendoring external runtimes.

## Product management

- [product-on-purpose/pm-skills](https://github.com/product-on-purpose/pm-skills) — Apache-2.0. Used for the Triple-Diamond progression, explicit risk review, PRD scope boundaries, observable Given/When/Then acceptance, edge-case coverage, and launch go/no-go discipline.
- [deanpeters/Product-Manager-Skills](https://github.com/deanpeters/Product-Manager-Skills) — reviewed for comparison only. Its CC BY-NC-SA license makes direct incorporation unsuitable for this repository.

## Company-role loop

- [garrytan/gstack](https://github.com/garrytan/gstack) — MIT. Used for the role sequence of product/CEO review, design review, engineering review, QA, and release; also for hierarchy-as-service, subtraction, trust, and failure-path thinking.
- The gstack runtime itself is intentionally not installed or vendored. Its global state, telemetry, upgrade, browser-daemon, routing injection, and release commands are outside this project's guardrails.

## Design methods already used by this project

- [pbakaus/impeccable](https://github.com/pbakaus/impeccable) — product-interface hierarchy, progressive disclosure, audit, distill, adapt, and polish.
- [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) — touch-target, mobile density, responsive, and truthful time-series design references.
