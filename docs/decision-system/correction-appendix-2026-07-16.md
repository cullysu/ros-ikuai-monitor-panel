## 必须撤回的结论

1. 不能再写“时区问题只是测试写死”。旧生产契约确实输出过无时区时间；正确目标是后端统一 RFC 3339，前端拒绝无时区值。
2. 不能把 `navigator.onLine` 建模为面板正式 offline 状态。它只是一条浏览器提示，同源快照必须继续真实请求。
3. 不能写“装饰导航已经全部替换”。只能写“正式 React 路由已建立，旧壳层可见交互仍需全部收回”。
4. 不能把 19 个 URL 写成 19 个完成模块。模块完成必须包含真实搜索、筛选、排序、分页、对象详情和错误态。
5. 事故页已有证据却出现空白，是信息架构失误，不是“诚实留白”。
6. 证据台账不能固定展开或固定折叠，必须根据视窗和内容量自适应。
7. 手机稳定入口改为概览、网络、终端、日志四项，其余放入顶部更多菜单。
8. 不再使用 112px 全宽深色结论块；默认字号下目标是约 64–76px 的轻量状态区，并允许文字放大时自然增高。
9. 冷蓝只是强调色，不是核心设计原则。核心是对象密度、状态比较、操作效率和证据可信度。
10. 平板必须是侧栏、对象列表、详情检查器组成的任务架构，不以机械两栏冒充完成。
11. SVG 必须保持比例，并带时间窗、单位、比例尺和可访问说明；没有时间戳时不得把数字串成折线。
12. 安全结论必须收窄：主机校验、损坏配置、密码保存命名都以实际代码和测试为准。
13. 矩阵通过只代表工程发布证据，不代表产品和视觉验收通过。
14. 200% 文字缩放必须有真实浏览器重排证据，不能靠承诺或固定视窗检查代替。
15. 浏览器门禁只有在 Playwright 全局超时、上下文回收和失败工件均生效后，才可称稳定可复现。
