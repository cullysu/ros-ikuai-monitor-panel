# 爱快 4.0 手机巡检台重建合同

## 裁决

当前 `mobile-ikuai4` 表现层被产品所有者否决。它仍以卡片、桌面字段和固定表格式列表组织手机首屏，造成视觉中心弱、信息复读、短屏空间浪费和“后台缩小版”观感。旧 JSX、旧 CSS、旧截图基线和依赖其 DOM 数量的视觉门禁不得进入新实现。

允许保留的只有 API、领域证据、`current | historical | unavailable`、明确活动路由、原子流量样本和只读安全边界。

## 研究依据

爱快 4.0 的可迁移母语是：

1. WAN、接口、终端、采集通道以真实对象名出现；
2. 上传/下载、当前/峰值、在线/总量在同一阅读线上比较；
3. 主蓝只用于选中和操作，绿色用于已确认在线，橙红只用于已确认风险；
4. 白色主体、冷灰背景、细分隔、低圆角、低阴影；
5. 图表带对象、时间窗、单位、刻度、当前值和峰值；
6. 快捷入口直接抵达对象，而不是进入重复说明页。

iOS 只提供手机完成度标准：安全区、44px 命中区、稳定四根导航、清晰页面推进、Back/Forward、可中断短动效、Dynamic Type/200% 重排和不依赖颜色的状态。不得用大字号、毛玻璃、卡片堆叠或假 Sheet 冒充 iOS。

研究参考：爱快 4.0 实图与说明、爱快官方 App 的移动任务演进、Apple HIG；详细来源见 `docs/ikuai4-ui-study.md`。

## 选定方向

采用“场景接管式对象账本”，不是缩略仪表盘，也不是告警收件箱：

```text
设备 + 快照鲜度
→ 可验证结论
→ 当前最高风险对象
→ 同行关键比较
→ 一个直接调查入口
```

正常态由默认出口和 15 分钟可信趋势主导；资源满载由 CPU/内存/磁盘阈值与连续样本接管；接口事故由受影响接口对象接管；采集失败由 REST/SSH 和最后可信快照接管；全离线由 WAN 对象集合、默认路由和管理/采集/转发面边界接管。

Fleet 只是规模属性，不能盖过当前风险。

## 空间和视觉规则

- 320px 左右边距 12px；360–390px 为 14px；430px 为 16px。
- 设备栏 48–52px；状态带 40–48px；对象行 48–52px；底栏 56–60px 加安全区。
- 首屏核心结论区不得超过 76px，不使用 Hero。
- 页面背景 `#F5F7FA`，内容背景 `#FFFFFF`，主字 `#182230`，分隔 `#E6EBF1`，主蓝 `#2684FF`，在线绿 `#159F6D`，注意橙 `#D98A00`，故障红 `#D74747`。
- 模块圆角最多 6px；默认无阴影；浮层阴影最多 `0 4px 16px rgba(24,34,48,.10)`。
- 对象名 14–15px，正文 13–13.5px，元数据 11.5–12px，关键数值 19–22px；所有数字使用 tabular nums。
- 图表 136–160px，至少两个 Y 轴刻度和三个时间刻度，禁止 `preserveAspectRatio="none"` 拉伸。
- 只有能进入新证据的行才显示 chevron；不放“查看详情”大按钮。

## 手机根导航

固定四根：`概览 / 网络 / 终端 / 日志`。刷新和更多位于顶部；低频模块进入更多目录。不得把终端和日志藏进工具，不得使用五栏、光晕胶囊或装饰性房子图标。

## 场景验收

- 五种核心状态必须在三秒内仅靠结构和对象即可区分。
- 最高风险决定场景、首对象和主入口。
- 同一事实不得在状态、信号、对象三层复读。
- 缺失值不得变成 0；历史值不得显示为当前。
- 详情至少增加两个首页没有的新证据。
- 320×568、360×800、375×667、390×844、430×932、667×375、768×1024、844×390 全覆盖；不得按精确尺寸特供。
- 600px+ 使用导航—对象列表—详情工作区；不足以容纳三栏时退为两层任务流。
- 200% 文本、键盘、Back/Forward、焦点和滚动恢复、Reduced Motion、forced colors 全部有真实浏览器证据。

## 删除边界

必须删除当前手机首页、路由、导航、连接表现组件及全部 `mobile-ikuai4/styles`。新表现层使用新的独立目录和类名前缀，不复制旧 JSX、CSS 数值、卡片结构或截图。旧运行报告立即作废。

## 发布边界

Product、Design、Visual、Accessibility、state matrix 全部回到 `pending/stale`。只有新表现层通过独立原图评审、完整矩阵、真实 RouterOS soak、clean candidate 和获准上传后的精确 SHA Linux/Windows/GHCR CL，才可申请公众发布。
