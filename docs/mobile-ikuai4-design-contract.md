## 目标

手机端不是桌面控制台的缩放版，也不是 iQOO、OriginOS 或通用 iOS 小组件页面。新的视觉母语来自爱快 4.0：明确的网络对象、紧凑可比较的数据、浅色冷静表面、蓝色交互语义、完整时间轴和直接的运维入口。iOS 只作为触控、排版、动效和无障碍完成度的质量标尺。

首页只服务三个问题：

1. 当前网络是否可判断、是否需要处理；
2. 当前出口、采集和快照是否可信；
3. 最高优先级对象在哪里，点下去能得到什么新证据。

## 爱快 4.0 设计语言提炼

### 1. 颜色

- 页面底色为近白冷灰，不用壁纸、氛围光或整屏蓝灰染色。
- 主蓝只用于当前导航、可点击数据、选中标签和当前可信曲线。
- 绿色只表达明确的在线或下载语义；橙色只表达注意；红色只表达已经证实的故障。
- 低优先级区域用灰阶、边框和字重区分，不靠大面积半透明材质。

### 2. 面板与层级

- 爱快 4.0 的内容面板是低圆角、细边框、弱阴影或无阴影；圆角不是主视觉。
- 信息密度来自对象、列、单位、时间和比较关系，不来自缩小到不可读的字号。
- 淡蓝、淡紫、淡橙只用于小范围领域摘要，不把所有内容都做成彩色卡片。
- 首页允许多个模块，但每个模块必须回答不同问题，禁止默认出口、WAN 数量和路由状态复读。

### 3. 数据与对象

- WAN、接口、终端和应用必须以对象名出现，不用“巡检 WAN”“查看详情”替代对象。
- 速率必须同时带方向、单位和采样时间；图表必须有时间窗、当前值、峰值或比例尺。
- 排行必须包含对象身份、上传、下载、总量或占比中的有效比较项。
- 缺失、历史和不可用不显示为零；无法验证活动路由时明确显示“未确认”。

### 4. 导航与操作

- 手机稳定保留四个任务根：`概览 / 网络 / 终端 / 日志`。
- 更多、刷新和连接属于顶部工具，不占第五个底部根。
- 详情必须增加时间、来源、关联对象、阈值或原始证据，不能把首页内容放大再念一次。
- Back、Forward、焦点恢复和滚动恢复是正式契约。

## 手机转译原则

### 不能照搬桌面的部分

- 左侧多级侧栏；
- 横向八列以上表格；
- 巨型系统概览横幅；
- 一屏并排多张完整桌面图表；
- 用 1366px 的模块顺序机械改成单列；
- 桌面快捷入口九宫格；
- 以大量空白包围少量字段。

### 必须保留的爱快基因

- 对象优先：`pppoe-wan1`、`ether5`、`REST`、`SSH` 等名称直接可见；
- 比较优先：同一行比较上下行、当前/峰值、在线/总数、阈值/当前值；
- 状态优先：选中、在线、注意、异常使用统一且克制的单色语法；
- 图表可信：完整时间轴、单位和图例；
- 操作直接：点对象进入对象，不经过空泛的中转页。

## 390×844 信息预算

- 顶部设备栏：48–52px；设备名、版本/目标、刷新、更多。
- 运行状态带：40–48px；状态、证据鲜度、最高风险入口。
- 主监控面：128–176px；正常态给 WAN 速率和 15 分钟趋势，事故态给最高风险对象和影响。
- 对象摘要：每行 44–52px；首屏最多 4–5 行，不使用大号卡片。
- 底部导航：视觉 56–60px，命中区不小于 44px。
- 可见字号：辅助 11.5–12.5px，正文 13–14px，对象名 15–17px，主数值 19–24px；不使用桌面巨型标题，也不使用 7–9px 字号。

## 场景结构

### 正常

`设备栏 → 运行状态带 → WAN 监控面（当前上下行 + 15 分钟趋势 + 活动出口）→ 资源/接口/采集紧凑行 → 底部导航`

### 全离线

`设备栏 → 故障状态带 → WAN 对象清单（未运行原因/最后变化）→ 默认路由未确认 → 管理面与采集面边界 → 底部导航`

不得显示旧速率、零速率图表或“网络良好”。

### 采集失败 / 无快照

`设备栏 → 判断不可用状态带 → REST/SSH 独立结果 → 最近可信快照与受影响领域 → 连接入口 → 底部导航`

### 资源满载

`设备栏 → 资源告警状态带 → CPU/内存/磁盘三行压力比较（当前/阈值/连续样本）→ 受影响对象或事件 → 底部导航`

### 接口故障

`设备栏 → 接口告警状态带 → 故障接口行 → 关联路径 → WAN 当前证据 → 关联日志入口 → 底部导航`

### Fleet

最高风险先于规模；只有没有事故时才展示在线设备与总设备比较。

## 动效与无障碍

- 按压反馈 100–140ms，仅使用 transform/opacity/color；不使用 `transition: all`。
- 页面推进 180–220ms，可中断；reduced-motion 下取消位移，仅保留必要淡入。
- 200% 文字下改为单列和内容驱动高度，不截断对象名、单位或状态。
- 强制色模式不依赖色块表达状态；状态必须同时有文字和图标/形状。
- 触控目标不小于 44px，但视觉行高可为 36–40px，通过透明命中区补足，避免老年机体积。

## 方向门禁

进入生产前必须比较三个真正不同的 390×844 可运行方向：

1. `A / Mobile System Overview`：总览状态带 + WAN 监控面 + 紧凑对象行；
2. `B / Line Monitor First`：端口/线路为主对象，图表和关系前置；
3. `C / Incident Queue First`：异常队列驱动，正常态才退回线路摘要。

胜出方向必须满足：没有壁纸、没有华容卡片网格、没有桌面 KPI、没有首页字段复读、正常与事故结构不同，并能在 390×844 首屏内完成三秒判断。
