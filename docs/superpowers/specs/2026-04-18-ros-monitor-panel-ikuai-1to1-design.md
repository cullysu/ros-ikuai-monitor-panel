# ROS 监控面板 iKuai 4.0 1:1 重构设计

## 1. 目标

将现有 RouterOS Web 监控面板重构为纯监控类、iKuai 4.0 风格的只读面板。

本次重构以用户已部署的 iKuai 4.0 虚拟机界面作为直接参考，优先复刻：

- 左侧导航壳层
- 顶部状态栏与页面标题区
- 首页信息节奏
- 各功能页的模块归属方式
- 卡片、表格、图表的摆放逻辑
- 刷新工具条的位置与交互

同时保持 RouterOS 原始数据来源不变，只做“爱快化展示”，不引入任何设置、保存、修改、启停能力。

## 2. 约束

- 仅展示 RouterOS REST/SSH 可读取数据。
- 所有页面必须只读。
- 不伪造 RouterOS 无法稳定读取的指标。
- 不新增前端框架，继续使用当前 Python + 单文件 HTML 架构。
- 历史设计稿曾使用固定局域网地址；当前公开项目统一使用 `http://127.0.0.1:28646/`。

## 3. 设计原则

### 3.1 壳层复刻

整体布局向 iKuai 4.0 靠拢：

- 左侧固定导航
- 顶部固定状态栏
- 右侧内容区卡片化展示
- 首屏先看摘要卡和主表，图表放后

### 3.2 首页减负

首页只保留宽带核心信息，不再承担全部监控功能。

### 3.3 功能归类

详细能力全部进入对应监控中心，避免乱堆。

### 3.4 只读可证

拿不到的数据明确显示 `未采集` 或 `-`，不模拟、不猜测。

### 3.5 刷新统一

所有主要监控页共享同一套刷新工具条与逻辑，默认自动刷新 `1 秒`。

## 6. 刷新工具条设计

所有主要页面统一使用同一套刷新工具条，位置在页面标题右侧或内容首部。

包含组件：

- `手动刷新` 按钮
- `刷新模式` 选择
  - 手动
  - 自动
- `秒数输入框`
- `最后刷新时间`
- `当前刷新方式`
- `自动刷新倒计时`

规则：

- 默认自动刷新 `1 秒`
- 手动刷新只执行一次，当前刷新方式显示为 `手动`
- 自动刷新持续轮询，当前刷新方式显示为 `自动`
- 手动与自动逻辑必须分离
- 各页面使用统一视觉样式与控件顺序

## 8. 数据映射策略

当前后端已具备大部分所需数据，只需要做页面重排和少量字段补齐。

映射原则：

- iKuai 的“可读监控”模块优先映射已有 RouterOS 字段
- 没有稳定字段的项目显示 `未采集`
- 不为了像而伪造数据

需要重点复用的后端构建函数：

- `build_overview`
- `build_interfaces`
- `build_terminals_and_connections`
- `build_dhcp`
- `build_dns`
- `build_security`
- `build_load_balance`
- `build_logs`
