# 移动端产品契约（mobile product contract）

> 本文件是移动端（React surface）信息架构与交互的**唯一权威契约**。
> 生成日期：2026-09-30。取代仓库历史中"四个稳定入口"的旧口径
> （该口径属于 codex 分支时代的草稿，已被用户裁决取代）。

## 决策来源

- 2026-09-28：用户明确指定 `手机UI草图生成v2/输出/`（28 张，五 Tab）为
  最终视觉与信息架构基线。
- 2026-09-30：用户确认按该基线交付并全量验证（虚拟数据 16/16 ALL PASS，
  生产部署 10/10 ALL PASS）。

## 信息架构（冻结）

底部固定 **5 个 Tab**：

| Tab | 内容 |
|---|---|
| 首页 | 设备身份（真实 identity）、WAN 汇总、在线设备、快捷入口 |
| 网络 | 线路状态（含默认出口标记）、接口、路由、分流、DNS |
| 安全 | 防火墙/ACL、终端风险视图、IP 别名改名（唯一写操作，受开关保护） |
| 日志 | 日志中心（含截断披露）、服务日志、只读诊断入口 |
| 更多 | 设备资料（真实 identity）、网络配置、诊断与采集、全局搜索、退出登录 |

- 低频路由进入"更多"或所属 Tab 的二级页；不再有第四/第六个固定 Tab。
- 领域归属以本表为准：终端在"安全"、只读诊断在"日志"是**既定设计**，
  不再视为缺陷（推翻需用户裁决）。

## 交互契约

- 导航项必须同时改变 URL、标题、内容、焦点与数据所有权；仅组件 state 的
  Tab/筛选是过渡态，不承诺深链（分批补 URL 同步）。
- `未采集 / 未知 / 离线` 三态必须分开渲染，不得互相冒充。
- 搜索弹层：打开入历史栈、关闭出栈、popstate 关闭、监听器随卸载清理。
- 退出登录 = 断开回连接页（密码本就不保存）。

## 交付形态（P1-27 的正式答复）

- **当前**：手机与面板同处家庭网段，通过浏览器访问 LAN 内面板地址；
  iKuai NTR RouterOS Android 壳（姊妹仓库 APK）内置同一 React surface，
  直连面板 API。
- **明确不做**：公网后端、云账号、远程隧道（只读面板的威胁模型不匹配）。
