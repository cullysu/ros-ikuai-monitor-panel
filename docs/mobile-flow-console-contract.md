# Mobile Flow Console — 手机端零基线设计合同

- status: `current-design-candidate`
- decision step: `1049`
- release effect: `FAIL / CLOSED`
- scope: 手机与平板呈现；桌面 JSX、布局与样式不得进入该树

## 为什么再次推翻

当前 `mobile-native-ui` 虽然修正了证据真假，但视觉骨架仍是“标题 + 状态说明 + 若干白卡 + 浮动导航”。它把桌面监控模块切成较大的手机卡片，导致 390px 正常态下半屏空、320px 节奏被挤压、768px 只是两张手机卡并排。用户无法像使用成熟手机 App 那样沿一条拇指路径完成判断。

因此本轮禁止继续调圆角、阴影和卡片间距。旧呈现只可作为反例，不能作为新结构的组件来源。

## 产品主线

手机首页只回答四个连续问题：

1. **现在能否判断？** 当前 / 历史 / 不可用与证据时间。
2. **哪条路径或哪个对象决定结论？** 默认出口或最高风险对象必须紧邻结论。
3. **决定性数字是什么？** 只显示当前且原子完整的速率、阈值、连续样本或通道状态。
4. **下一次点按去哪？** 最多三条对象队列，整行直达真实详情。

proof、signal、object 不再各自形成一张同权卡片。每条信息只拥有一个首要位置。

## 几何与视觉

### 390×844

- 52px 紧凑导航栏：设备名、20px 页面标题、两个 44px 图标按钮。
- 62–70px 全宽状态轨：结论、鲜度、证据时间和决定对象，同一区域完成，不做 hero 卡。
- 112–148px 场景专属仪表：正常为 WAN 路径 + 双向速率 + 15 分钟趋势；事故为因果链、通道对照、资源比较或证据撤回清单。
- 28px 分区标题 + 48–52px 对象行；首屏至少露出两条可点对象。
- 56px 浮动 Liquid Glass 根导航，只属于控制层。

### 视觉语言

- 内容层采用边到边的冷白工作面，靠 1px 分隔线、4px 状态轨、同行对齐建立密度；禁止连续圆角白卡。
- 每个场景最多一个低圆角仪表容器。对象队列使用原生列表，而不是卡片田。
- 爱快蓝只用于当前路径、选中和可操作信息；绿/琥珀/红只用于已证实状态，不给整个页面染色。
- 11–12px 元信息、13–15px 正文、16–20px 结论/对象名、20–24px 当前数字。触控命中区仍不小于 44px，但视觉元素不能被放大成“老年机”。
- 图标只识别 WAN、接口、路由、采集、资源、终端对象；不使用装饰拓扑和通用彩色图标卡。

## 七场景必须不同构

| 场景 | 场景专属主仪表 | 禁止出现 |
|---|---|---|
| single | 默认出口同行 + 当前上下行 + 双序列趋势 | 健康大卡、重复 WAN 状态 |
| fleet | 风险分布 + 最高风险设备/对象队列 | 用设备规模盖过事故 |
| all-offline | 默认出口断链链条 + 受影响 WAN/路径 | 旧速率、正常排行 |
| no-snapshot | 已撤回数字清单 + 恢复采集步骤 | 任何当前业务值 |
| collection-down | REST/SSH 独立通道对照 + 来源边界 | 用管理面失败推断转发面失败 |
| resource-full | 当前/阈值/末尾连续样本三列比较 | 三层重复 CPU/内存/磁盘 |
| interfaces-down | 默认路由 → 第一责任接口 → 关联对象的因果链 | 分散卡片让用户自己拼因果 |

## 手机交互

- 四个稳定根：概览 / 网络 / 终端 / 日志。
- 对象进入真实 push detail；Back 和 Forward 都恢复选中对象、滚动和焦点。
- 搜索、筛选、排序只在对象目录出现，不挤占概览。
- 点击反馈 140–180ms `scale(.98)`；可中断，无弹跳。减少动态时移除位移动画。
- Liquid Glass 只用于顶部工具、根导航和连接提交控制，不覆盖数据内容。

## 平板与横屏

- 600–899px 是真正的 master/detail：左侧 280–320px 风险对象列表，右侧当前对象证据；没有选中对象时，右侧展示场景仪表和默认对象，不允许空白占位。
- 667/844 横屏把状态轨与主仪表放左侧，对象队列放右侧；不是把竖屏卡片横排。
- 900px 起由桌面树接管；两端只共享证据模型、对象身份、路由和时间契约。

## 工程边界

- 新呈现所有者：`src/panel-framework/mobile-flow-ui/`。
- 可以共享证据模型、领域行模型、历史状态和运行时控制器；不得导入旧手机呈现组件或旧 CSS。
- 新树挂载并通过聚焦 smoke 后，物理删除 `src/panel-framework/mobile-native-ui/`。
- 验收选择器使用 `data-mobile-flow-*` / `mflow-*`，不得用 retired owner 的 OR 条件假绿。
