## 设计执行原则

1. **Proof、Signal、Object 不复读**：Proof 回答“凭什么判断”；Signal 回答“现在变化多大”；Object 回答“具体检查谁”。
2. **最高风险优先**：事故类型决定首页焦点和默认领域，Fleet 只描述规模，不能覆盖接口、WAN、采集或资源事故。
3. **可见控件必须真实**：没有行为的搜索、按钮、链接和拖拽暗示全部删除，不以“以后实现”保留在公开界面。
4. **未知保持未知**：缺失速率不改写为零，未核实路由不选择任意首行，失败端点未记录不表述为零故障。
5. **响应式按任务重构**：手机是巡检队列，平板是列表—详情工作区，桌面是控制台；不是同一 DOM 的机械缩放。
